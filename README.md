# 까비와 세종의 발명 연구소

횡계초 5머루 친구들이 푸는 **5학년 2학기 사회 2단원 [6차시] 조선의 발전에 따른 사람들의 생활 모습** 미션 게임입니다.

- 미션 5개를 차례로 풀면 발명품(농사직설 · 앙부일구 · 측우기 · 훈민정음 · 갑인자)을 하나씩 얻어요.
- 서술형 문제는 15자 정도로 짧게 써요(6자 이상, 18자 이하). 쓴 답은 선생님 시트로 가요.
- 문제를 맞혀야만 다음 문제, 다음 미션으로 갈 수 있어요.
- 발명품 5개를 모으면 최종 관문 **발명 빙고**를 풀고 세종 임금님의 칭찬 교지를 받아요.
- 학생 기록(시작, 미션 완료와 틀린 횟수, 서술형 답, 최종 결과)은 선생님 구글 스프레드시트로 보내져요.

## 선생님: 기록 받기 준비 (처음 한 번만)

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만들어요.
2. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 원래 있던 코드를 지우고 `apps-script/Code.gs` 내용을 모두 붙여 넣은 뒤 저장해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 허용 → 나오는 **웹 앱 URL**(…/exec)을 복사해요.
6. 앱 맨 아래 **선생님 설정**에 주소를 붙여 넣고 **저장 → 시험 기록 보내기**를 눌러 시트에 줄이 생기는지 확인해요.
   - 화면에 나오는 **학생용 링크**를 나눠 주면 학생 기기에도 주소가 자동으로 기억돼요.
   - 또는 `config.js`의 `GAS_URL` 따옴표 안에 주소를 넣어 두면 모든 기기에서 바로 기록돼요.

## 스프레드시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| 기록 | 학생이 보낸 기록이 한 줄씩 쌓여요 (구분: 시작 / 미션완료 / 서술형 / 최종통과) |
| 학생현황 | 학생마다 한 줄: 진행 단계, 엽전, 서술형 답, 최종 결과 |
